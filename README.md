Part 1. Profile Object, Data Types & Arithmetic:

Task 1. The Personal Info Object: Created a JavaScript const object (readerProfile) storing various data types including a string (fullName), a number (birthYear), a boolean (isActiveReader), and an array of strings (favoriteBooks).


Task 2. Arithmetic Calculations: Implemented a script using arithmetic operators to dynamically calculate the reader's current age by subtracting birthYear from the current year using new Date().getFullYear(). Computed additional metrics like age in months and total book count, displaying all outputs in the browser console alongside the complete profile object.

Part 2. Form Input & Event Responses:

Task 3. HTML Form Setup: Designed an HTML form with input fields for Reader Name (<input type="text">) and Birth Year (<input type="number">), complete with proper <label> elements and a "Save Reader" submit button.

Task 4. Event Listener: Added a click event listener to the button that captures user input, updates the readerProfile object dynamically, performs age calculations, and prints the updated state to the console while preventing the default form submission behavior.


Part 3. DOM List Manipulation:

Task 5. Creating & Removing Elements: Built an unordered list (<ul id="bookList">) with pre-populated book items. Implemented an "Add Book" button and text input (bookInput) to dynamically create and append new <li> elements. Created a "Remove Last Book" button utilizing lastElementChild and removeChild to safely delete the final item from the list.
