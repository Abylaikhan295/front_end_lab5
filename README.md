Part 2. Bootstrap Forms:


Task 2. Bootstrap Form Styling
Recreated the contact form using Bootstrap 5 form classes (`form-control`, `form-label`).
Utilized Bootstrap’s responsive grid system (`row`, `col-md-6`) to neatly organize form fields side by side.
Added descriptive placeholders and helper text (`form-text`) to enhance user experience.

Task 3. Bootstrap Validation Styles
Applied Bootstrap’s explicit validation feedback classes (`is-valid` and `is-invalid`) to demonstrate success and error states.
Integrated validation feedback message divs (`valid-feedback`, `invalid-feedback`) below inputs (e.g., “Email is required”, “Looks good!”).
Tested the visual appearance of valid and invalid input borders and messages.

Part 3. Advanced Form Project:


Task 4. Registration Form
Created a comprehensive user registration form containing:
First Name and Last Name inputs
Email input
Password and Confirm Password fields with minimum length validation (`minlength="6"`)
Gender selection using inline radio buttons (`type="radio"`)
Hobbies selection using checkboxes (`type="checkbox"`)
Country selection dropdown (`<select>` with disabled default option)
Submit and Reset buttons
Styled the entire form using Bootstrap Grid classes to make it fully responsive across devices.
Integrated both HTML5 native constraints and Bootstrap validation feedback styles.
